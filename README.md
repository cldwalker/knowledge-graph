## Description

This website is my link blog that uses [my ontology](https://tagaholic.me/schema/).

## Development

Install [babashka](https://github.com/babashka/babashka). Most useful bb tasks:
* `bb quickblog` - Invoke [quickblog](https://github.com/borkdude/quickblog) tasks

The posts are generated with the `logseq-publish-graph` CLI in https://github.com/cldwalker/bb-clis.

## Contributing

I'm not looking for major contributions as this is my personal website. I'm sharing the code so others can see how to publish their links using an ontology.
